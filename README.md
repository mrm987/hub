# 모리모 게임 허브

크랙 플랫폼의 스토리챗을 기반으로 한 미니게임 허브 페이지입니다.

## 게임 목록

### 1. 페로 폰 훔쳐보기
- **링크**: https://perrophone.chat-img.cc
- **원본 스토리챗**: 경찰과 괴도

### 2. 지원군 요청하기
- **링크**: https://threemessengers.chat-img.cc
- **원본 스토리챗**: 3인의 전령

## 기술 스택

- HTML5
- CSS3
- 모바일 반응형 디자인

## 특징

- ✨ 모바일 환경 최적화
- 📱 반응형 레이아웃 (세로/가로 모드 지원)
- 🎨 모던한 UI/UX 디자인
- 🔗 각 게임으로 직접 연결

## 로컬 실행

저장소를 클론한 후 `index.html` 파일을 브라우저에서 열면 됩니다.

```bash
git clone <repository-url>
cd hub
open index.html
```
